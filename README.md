# cs628-pe-hao-yan

Input
The input of this program consists of the resume information provided by the developer. This includes personal details such as name, contact information, education background, skills, work experience, and project descriptions. These data elements are hardcoded into the React component and serve as the content to be displayed on the web page.

Process
The program processes the input using a React application. The Resume component organizes the input data into structured sections using JSX syntax. The App component renders the Resume component as the root component. CSS styles from Resume.css are applied to format the layout, including fonts, spacing, and background color. React dynamically renders the content into the browser through the virtual DOM.

Output
The output is a well-structured and visually styled web page displaying the resume information. The page includes clearly separated sections such as education, skills, and projects, making it easy to read and navigate. The final result is a user-friendly resume interface rendered in the browser.
